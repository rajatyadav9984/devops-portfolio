## 💻 How to Run Locally

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/rajatyadav/devops-portfolio.git
   cd devops-portfolio
   ```

2. **Open directly in browser**:
   Simply double-click `index.html` or open it with your favorite web browser.

3. **Or run with a local web server**:
   Using Python:
   ```bash
   python -m http.server 8080
   ```
   Or using Node.js:
   ```bash
   npx serve .
   ```
   Then navigate to `http://localhost:8080` in your browser.
